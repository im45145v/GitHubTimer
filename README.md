# GitHubTimer

GitHubTimer is a simple client-side focus clock and countdown timer where the timer itself is rendered as a GitHub-style contribution grid.

## Features

- Contribution-square digital clock mode
- Custom countdown timer mode with quick presets
- Start, pause, resume and reset controls
- Focus session tracking with optional labels
- GitHub-style historical contribution graph
- Local persistence with accurate inactive-tab countdown behavior
- Export, import and reset data tools

## Usage

Open `index.html` in a browser, or host the repository directly on GitHub Pages.

All data is stored locally in the browser with `localStorage`, so no backend or build step is required.
